## 1. 产品定义摘要

- **形态**：蛋形/胶囊挂件，Ø42-48mm × 高 55-65mm，约 55-70g，可换硅胶套，挂包/桌面两栖
- **屏幕**：彩色圆屏，深底霓虹像素风（48×48 宠物本体整数倍放大）
- **交互**：正面 3 键（选择/确认/返回）+ 侧面 PTT 语音键 + 壳体触摸摸头 + 摇晃/计步
- **智能**：端侧唤醒词+离线命令词；云端 ASR→LLM→TTS 对话大脑；本地需求循环永不掉线
- **连接**：Wi-Fi 2.4G（云端大脑）+ BLE（配网、宠物见面社交）
- **成本目标**：量产 BOM ≤ ¥190，售价 ¥299-399

## 2. 系统架构

```
                    ┌──────────────── ESP32-S3 (N16R8) ────────────────┐
 INMP441 麦克风 ──I2S─▶│                                                  │
 MAX98357A 功放 ◀─I2S──  │  渲染任务(30fps)  行为任务(需求循环)  输入任务      │
 8Ω 1W 喇叭    ◀──────  │  网络任务(MQTT/HTTP)  语音任务(WakeNet/MultiNet)   │
                     └──────┬──────────┬──────────┬──────────────────────┘
 3×正面键+PTT ────GPIO───────┤          │          │
```

## 3. 核心选型

| 模块 | 开发/手板 | 量产 | 理由 |
|---|---|---|---|
| **主控** | ESP32-S3-WROOM-1-N16R8 模组（16MB Flash + 8MB PSRAM） | 同左，量产后可转 chip-on-board 降本 | Wi-Fi+BLE 双模；ESP-SR 离线唤醒/命令词；原生 USB 免串口芯片；PSRAM 放帧缓冲双缓冲 |
| **屏幕** | 二选一：① GC9A01 1.28" IPS 圆屏 240×240（SPI，¥25）② LILYGO T-Display-S3 AMOLED 2.1" 圆屏 480×480 整板（≈¥200） | **RM67162 1.43" 圆形 AMOLED 466×466（QSPI）** | 深底霓虹像素 = AMOLED 真黑最搭；暗 UI 省电；LILYGO 板同用 RM67162 驱动，代码直通量产。预算紧则量产退回 IPS |
| **麦克风** | INMP441 I2S 数字麦模块 | 同级 MEMS（敏芯/Zilltek，¥1.5-3） | I2S 全数字，抗干扰，唤醒+PTT 录音共用 |
| **功放+喇叭** | MAX98357A 模块 + 8Ω 1W 16mm 喇叭 | 同芯片 + 15/18mm 腔体喇叭 | I2S 直入；软件限幅 85dB（未来儿童模式的合规底线） |
| **加速度计** | SC7A20（I2C，¥1） | 同左 | 计步（探险玩法）、摇晃、敲击=敲蛋壳、摸头辅助判定 |
| **触摸** | ESP32-S3 原生电容触摸 + 壳内铜箔/弹簧 | 同左 | 零成本摸头交互；避免再加触控 IC |
| **光感** | 光敏电阻 + ADC（¥0.3） | 同左 | 天黑自动进待机屏保 |
| **电池** | 502030 250mAh LiPo（带保护板） | 同规格，带保护 IC（DW01+8205） | 挂件体积平衡点 |
| **充电** | TP4056 + USB-C（CC 脚 5.1k 下拉） | 同左，集成保护 | 磁吸 pogo 2P 底座充电（v1 无源底座） |
| **按键** | 3×3×4×2.5mm 贴片轻触（180gf，10 万次）+ 侧按 PTT | 同左 + 硅胶键帽 | B 键帽带凸点；力值轻脆有解压感 |
| **接口** | USB-C（充电+烧录，S3 原生 USB） | 同左 | 无需 UART 桥芯片 |

## 4. 交互硬件 → 功能映射（与按键设计稿一致）

| 硬件 | 功能 |
|---|---|
| A 键（左） | 切换选项；长按 = 快捷环菜单 |
| B 键（中，凸点） | 首页 = 打招呼（宠物回应）；菜单 = 确认；长按 = 主菜单 |
| C 键（右） | 返回；长按 2s = 口袋模式（息屏+静音） |
| PTT 侧键 | 按住说话、松开发送；休眠中按住 = 唤醒 |
| 触摸区（壳内弹簧） | 摸头：心情+；孵化期 = 温柔抚摸加速 |
| 加速度计 | 计步→探险里程；摇晃 = 互动；敲击 = 敲蛋壳 |
| 光敏 | 暗环境自动待机屏保 |
| 工程组合键 | A+C 长按 5s 重启；B+PTT+插电 = 配网；三键 10s = 恢复出厂 |

## 5. 电源与功耗预算

| 场景 | 主要负载 | 平均电流 | 250mAh 续航 |
|---|---|---|---|
| 口袋模式（息屏待机） | S3 deep sleep + 触摸/加速度唤醒 | 0.05-0.5mA | **5-10 天** |
| 挂机（屏亮屏保，Wi-Fi 断续同步） | 屏 + MCU light sleep | 8-20mA | 1-2 天 |
| 互动（亮屏+对话） | 屏 + Wi-Fi 突发 + 音频 | 150-250mA 峰值 | 2-4 小时连续 |
| 充电 | TP4056 0.5C | — | 约 1 小时充满 |

设计策略：动画静止时降帧至 5fps + 亮度 30%；Wi-Fi 按需唤醒（每 10 分钟同步台词队列）；对话语音走突发，结束后立即回挂机态。**"回巢充电"做成产品仪式**（放回窝 = 晚安动画），弱化续航焦虑。

## 6. 结构与声学

- 蛋身两件式（前壳+后壳，超声波焊或螺丝柱），硅胶套包覆换壳
- 屏窗：亚克力/PMMA 片 0.8mm，AMOLED 表面自带偏光可不加
- **声学**：麦克风开孔 Ø1mm + 防尘网，远离喇叭（防啸叫）；喇叭后腔 ≥0.8cm³ 密封，出音孔避开挂绳孔
- **射频**：模组天线区 8mm 净空，壳内金属件（磁铁、弹簧）远离天线侧；磁吸触点放底部
- 跌落目标：1.2m 六面（硅胶套状态），玩具级日常抗造

## 7. 语音链路（硬件视角）

```
PTT按下 → I2S 16k 采样 → (Opus/PCM) → Wi-Fi → 网关
  → 云端流式 ASR（豆包/讯飞）→ LLM（GLM-4-Flash，≤14字约束）
  → 流式 TTS 回传 → MAX98357A 播放；目标 P95 < 2.5s
离线兜底：WakeNet 唤醒词「蛋生蛋生」+ MultiNet 命令词（喂食/睡觉/跳舞…约100条）
按键音 = 宠物叫声：S3 方波直合成（不同键不同音高）；对话 TTS 出生即解锁（无幼年期）
```

## 8. 三阶段硬件路线

### Stage 0 · 开发原型（本周可开工，零 PCB，预算 ≈ ¥600）

| 物品 | 数量 | 参考价 | 用途 |
|---|---|---|---|
| LILYGO T-Display-S3 AMOLED **2.1" 圆屏**版 | 1 | ¥180-230 | UI/形态验证（RM67162 与量产同驱动） |
| 乐鑫 ESP32-S3-Box-3 | 1 | ¥230-280 | 语音栈验证（双麦+喇叭+屏，ESP-SR 官方支持） |
| INMP441 模块 + MAX98357A 模块 + 16mm 喇叭 | 各1 | ¥15 | 给 LILYGO 板补音频 |
| 轻触按键模块 ×4 + 杜邦线 + 面包板 | 1套 | ¥15 | 按键交互 |
| 502030 电池 + TP4056 模块 | 1 | ¥12 | 供电测试 |

双线并进：Box-3 调语音云链路，LILYGO 调像素 UI，代码在真机上汇合。

### Stage 1 · 外观手板（2-4 周，≈ ¥800）

- 3D 打印蛋形外壳 2-3 版（树脂精度更好），内嵌 Stage 0 模块
- 硅胶键帽手板、触摸弹簧贴装、喇叭腔体验证
- 产出：可以挂包上、能对话的第一台"真机"，拿给种子用户/儿子玩

### Stage 2 · EVT 自研 PCB（1-2 月，10 台 ≈ ¥2500）

- 4 层板 ≈40×55mm，嘉立创打样+SMT（板+料约 ¥180-250/台）
- 量产屏 RM67162 1.43" 466×466 模组打样（¥60-80/片）
- 完整传感器+电源+磁吸触点；结构件继续 3D 打印

### Stage 3 · DVT 小批量（50 台）

- 硅胶套手版模（¥3-8k）、装配工艺验证、老化与跌落测试
- 云端压测：单宠物 API 成本核算 → 定价订阅

### Stage 4 · MP 量产

- 硬模开发（蛋身 ABS 模 ¥15-30 万，硅胶套模 ¥3-5 万）——**建议首发用 3D 打印批量化工艺（如 MJF/尼龙烧结）压低模具门槛，验证销量后再开硬模**
- 认证：SRRC 型号核准（Wi-Fi/BT 必需）、ROHS、电池 UN38.3/CB；定位 16+ 潮玩可避开玩具 CCC 与未成年人额外要求（若后续做儿童版再补）
