> v1.2 同步批阅决议：**每日节律**（早晨首次抬腕 = `💤✨` 讲梦；晚安仪式）；**放生改宠物先表达远行愿望**（`🌍✈️` 送行叙事，替代主人主动选择）；**屋子 3 只全部并行挂机**；**毒舌闹钟**进 v1（本地通知，不占 UI 页面）；**客房卡**预留；v1 纯手表单打；单一主人设定

## 1. 设计原则

1. **宠物是主角，UI 是道具**——每一页 60% 以上面积留给宠物舞台，控件退到边缘；界面上唯一持续动画的东西是它
2. **像素风 × 系统壳**——像素字/像素图标/深底扫描线构成世界观；导航、滚动、转场遵循 watchOS 原生习惯（ Liquid Glass 壳里装一台 8-bit 游戏），用户不需要学任何新手势
3. **低存在感是美德**——表盘上低频微动、App 内不抢时间、一天主动开口 ≤2 次；宁可被想念，不可被嫌吵
4. **给 5-10 岁的触控目标**——可点元素最小 44×44pt、主操作单手可达、少文字多图标、每个操作有即时可感反馈（动画+Haptic）

## 2. 画布与布局系统

- **基准画布**：416×496（46mm）；内容安全区：顶部 ~24px（状态），左右 ~24px，底部 ~56px（手势预留）
- **宠物舞台**：主页核心区 384×384 —— **48×48 本体 ×8 整数放大**，深底扫描线+星尘背景（采样器背景原样平移）
- **网格**：8px 基础网格；像素内容永远整数倍缩放（×1/×2/×4/×8），禁止非整数倍（保像素锐利）
- **圆角**：屏幕本身圆角由系统裁切；卡片内直角（像素世界观里没有圆角卡片，只有描边矩形）

## 3. 色彩系统

| 角色 | 色 | 来源/用途 |
|---|---|---|
| 深底 | `#08090d` / `#05060a` | App 全局背景、宠物舞台底 |
| 扫描线 | `#0a0d14` / `#0d1119` | 舞台隔行线 |
| 星尘 | `#1c2432` | 背景点缀 |
| 描边 | `#181425` | 像素本体与 UI 元素统一外描边 |
| 面板 | `#10141d` + 描边 `#1d2430` | 卡片/列表底 |
| 主强调 | `#2ce8f5`（青霓虹） | 可点、进行中、链接 |
| 次强调 | `#b55088`（紫电）= 稀有 · `#fee761`（电光黄）= 史诗/传说 · `#63c74d`（荧光绿）= 成功 · `#e43b44`（警报红）= 警告/嫌弃 | 全部来自 Endesga-32，稀有度色与基因系统共用 |
| 正文 | `#e8eaf0` / 次要 `#7d8698` | 系统字文本 |

- 全局仅深色模式（AMOLED 省电 + 世界观一致）；跟随系统变亮时只提升底色亮度不反转
- 对比度：正文对深底 ≥4.5:1；霓虹色只用于强调不用于长文本

## 4. 字体系统（双轨制）

| 轨道 | 字体 | 用途 |
|---|---|---|
| 像素轨 | **Fusion Pixel（缝合像素字体，OFL 开源，含中文）** | 宠物名字、台词气泡、心情/数值标签、按钮主文案、时间数字——风格担当 |
| 系统轨 | SF Compact（watchOS 原生） | 说明性长文案、设置项、辅助小字——可读性担当 |

- 像素字最小 20pt 起（12px 骨架 ×2），低于此换系统字
- 台词气泡内一律像素字 + 打字机逐字，是"它在说话"的核心质感

## 5. 宠物渲染规格

- 本体 48×48，图层拆分：背景 / 光垫 / 身体 / 花纹 / 眼 / 天线 / 前景粒子——与采样器渲染管线一致，移植为 SwiftUI Canvas 逐帧绘制
- 状态机（复用采样器）：`idle 呼吸±1.5px / blink 眨眼 / happy 蹦跳+心粒子 / eat 进食吸收 / sleep 休眠Zzz / teleport 溶解-spinner-重组 / annoyed X眼 / glitch 后处理`
- 互动态 30fps；list 缩略图 ×2 静态帧 + 呼吸单动画；表盘 timeline 静态帧
- glitch 基因控制频率（低/中/高频）， rare 基因特效（全息流转色相/星尘微粒/黑洞吸积/双生残影）按 rare-gene-lab 已验证实现平移

## 6. 信息架构

```
表盘 Complication（常驻）
   └→ 点入 App
        ├─ 主页（唯一日常页 · 三态：在家态 / 探险态 / 开箱过场）
        │    ├─ 对话：融入（气泡 + 🎤 听写 + 短语 chips）
        │    ├─ 喂养：融入（喂豆按钮 → 底部半层选豆 → 动画在舞台同屏上演）
        │    └─ 矿洞：融入（它离家后主页自动切探险态，开箱 = 舞台过场演出）
        ├─ 屋子（唯一管理页：总览 / 孵化 / 融合入口 / 放生入口）
        └─ 两个仪式演出：融合（自屋子进入）/ 放生（自屋子长按进入）
```

- **全 App = 2 页 + 3 演出 + 表盘**——App 里几乎没有"界面"，只有它的家
- 半层/气泡收起后，主页永远回到极简三件（宠物 / 心情 / 按钮）；任何页面边缘右滑回主页
- iPhone 端（二期）：图鉴全册 / 血统谱系 / 融合实验室大屏版 / 记忆相册

## 7. 页面与演出设计

> 结构总览：**2 页**（7.2 主页 / 7.3 屋子）+ **3 演出**（7.1 开局 / 7.4 融合 / 7.5 放生）+ **表盘**（7.0）。演出 = 全屏动画过程，非可驻留页面。

### 7.0 表盘复杂功能（全天式展示 · 最重要的一屏）

```
accessoryCircular（圆形）        accessoryCorner（角落）
    ╭──────╮                     零波 ▁▂▃
    │ 宠物  │                      ╭─────╮
    │ ×2   │                      │宠物×1│
    │ 帧   │                      ╰─────╯
    ╰──────╯
```

- 圆形功能：48×48 帧放大 ×2 填满 @2x 渲染区——**原生像素密度，极致锐利**，宠物就是表盘上的一个小房间
- 角落功能：宠物 ×1 + 名字缩写 + 心情色点
- **姿态集（timeline 预生成）**：休眠 → 待机呼吸 → 翻身换位 → 偶发 glitch → 回休眠，每 20-30 分钟一条 entry，一天 20-30 帧预算内
- 心情指示：帧角落 2×2 像素色点（绿=开心 / 黄=一般 / 红=需要关注 / 灰=睡）——不点开也知道它好不好
- 点入行为：tap 复杂功能 → 直达主页；它"主动找你"时复杂功能短暂换成 happy 帧 + Haptic tap

### 7.1 开局 · 星空坠落（首次启动 onboarding，目标 30 秒）

```
① 全屏星空，扫描线渐亮
② 流星拖尾坠落 → 蛎砸进屏幕中央（震屏+Haptic）
③ 蛎轻幅摇动 → 提示「点它」（像素字 + 手指icon）
④ tap → 白闪破壳 → 宠物登台（溶解重组动画）+ 叫声
⑤ 取名：🎤 大按钮听写 → 回显确认（「它听到了：__」✓/重说）
⑥ 完成礼：全身 happy 蹦跳 + 「欢迎回家」
```

- 零等待原则：从打开 App 到摸到活宠物 < 30 秒；无账号/权限墙，权限（麦克风/健康）在使用点即时请求
- 命名回显必须可重说（防同音字，名字 LLM 记一辈子）

### 7.2 主页（唯一日常页 · 三态一体）

**态 1 · 在家态（默认）：**

```
┌─────────────────────────┐
│ 09:41              ●心情  │ ← 像素字时间 + 心情色点
│ ╭───────────────────╮   │
│ │ 气泡区：它的台词      │   │ ← 打字机+停留淡出；无台词时完全透明
│ │ 「今天矿洞挖到豆啦！」│   │    台词与表情/动作同屏同步演出
│ ╰───────────────────╯   │
│      · ✦ 星尘 ·          │
│   ╔─────────────────╗   │
│   ║    （宠物×8）     ║   │ ← 舞台 384×384；气泡展开时宠物下移让位
│   ╚═══════════════╝   │
│   零波 ▂▃▅               │ ← 名字 + 像素血条式心情格（绿/黄/红三档）
│      [ 🫘喂豆 ]  [ 🎤 ]   │ ← 喂豆 44pt / 听写 64pt
│  [你好] [吃了吗] [跳舞]→   │ ← 短语 chips 横滑常驻底部
└─────────────────────────┘
```

- **tap 宠物 = 摸头**：happy 帧一轮 + 心粒子 + 轻震；睡时摸 = annoyed（嫌弃帧）
- 横滑舞台 = 屋内切宠（瞬移转场）

**对话（融入在家态，不跳页）：**
1. tap 🎤 → watchOS 系统听写界面接管（自带全屏 UI，零自绘）
2. 确认 → 回主页：我的话右侧气泡短暂显示 → 它头顶 loading 转（"认真想"）→ 它的气泡打字机 + 同步表情动作
3. 气泡未消失的 3 秒内再 tap 🎤 = 续聊窗
4. **它说话时 tap 舞台 = 打断 + 摸头二合一**（真实的孩子行为：没听完就摸它）
- 短语轮盘 = 底部横滑 chips（你好 / 吃了吗 / 跳个舞 / 晚安 + 教过的口头禅）
- 结构化返回 `{文本,动作,心情,事件}` 直接驱动舞台演出
- **不做历史回看**（最多上滑露最近 3 条）；主动开口 ≤2 条/天
- **每日节律演出（v1.2）**：早晨首次抬腕 = 它冒 `💤✨` 讲一个梦（昨夜 agent memory 的产物，记忆系统的每日可见出口）；说晚安/检测入睡 = 待机屏保；毒舌闹钟 = 本地通知（性格化铃声，无专属 UI 页）

**喂养（融入在家态，底部半层）：**

```
tap [ 🫘喂豆 ] → 底部弹起半层（屏幕下 40%，watchOS sheet 原生模式）

│ ┌─────┐ ┌─────┐ ┌─────┐ │
│ │知识豆│ │玩乐豆│ │安眠豆│ │ ← 横滑选中；首喂后显示口味基因「最爱:玩乐豆♥」
│ │ ◆◆  │ │ ◇   │ │ ☾   │ │
│ └─────┘ └─────┘ └─────┘ │
│        [ 投喂 ]           │
半层自动滑落 → 豆子飞进舞台 → 采样器 eat 序列同屏上演
```

- 讨厌的豆 → annoyed X 眼 + 吐出；饱食度无数值血条，用体型暗示（过量 = 变圆卡顿）

**态 2 · 探险态（它去挖矿，主页自动切换）：**

```
┌─────────────────────────┐
│ 09:41              ●心情  │
│ 气泡:「我出去挖矿啦，等我！」│
│   ⛏ 矿洞入口小动画         │ ← 洞口微光，偶尔冒一粒星尘
│   ▓▓▓▓▓▓▓░░░ 6,240 步    │ ← 像素格子进度条（HealthKit 真实步数）
│   回家还要 2h 41m         │ ← 分钟粒度，不做秒级跳动（省刷新预算）
│  深层奖励：🥚? ✦?          │ ← 蛋的悬念格（? 覆盖）
│           [ 🎤 ]          │
└─────────────────────────┘
```

- 抬腕即见进度，无需跳页；挖矿进度 = HealthKit 真实步数，深层矿区出蛋（稀缺层）
- [提前召回] 藏进长按舞台菜单——普通日子不出现，别诱惑孩子半途而废

**态 3 · 开箱过场（它到家后首次抬腕，自动触发）：**

溶解重组回舞台 → 背包逐格翻开（数据豆 / 稀有部件 / 朋友的信 / **蛋**）逐格 Haptic + 逐格音阶 → 气泡区报喜 → 回到在家态。每天至多一次的仪式，惊喜感全靠"它自己带回来的"。

### 7.3 屋子（唯一管理页）

│ ╭─────╮ ╭─────╮ ╭─────╮ │

### 7.4 融合仪式（演出 · rare-gene-lab 序列平移）

```
选两只（横滑卡组） → 确认页（双方基因预览+冷却提示）
   ↓
全屏仪式 4.2s：双体半透明溶解 → 汇聚成蛋 → 裂纹 + 抖动加剧
   → 白闪破壳 → 后代登台（稀有基因特效即刻呈现）
   → 传说：全屏 glitch + 「⚠ 检测到未知基因序列」红色横幅 + 重 Haptic
```

- 手表端 v1 = **发起 + 观看仪式**；基因预览/血统分析大屏版在 iPhone
- 传说基因是全产品最高演出规格，动用全屏 glitch + 横幅 + 三连重震 + 专属音

### 7.5 放生仪式（演出 · 情感重场，克制而庄重）

```
长按宠物卡 → 放生 → 二次确认（「它会被归档，你们的记忆保留」）
   ↓ 全屏渐暗
宠物缓慢溶解 → 碎成星尘向上飘散 → 空舞台上留一枚淡色轮廓帧
   → 「零波去流浪了」→ 归档徽章（图鉴留档标记）
```

- 无删除字样、无红色警告轰炸——它是告别不是惩罚；溶解动画慢速 + 单次轻震
- 归档入口在图鉴：「曾陪伴」页签可回看它的基因档案

## 8. 交互手势总表

| 手势 | 语境 | 行为 |
|---|---|---|
| tap 宠物 | 主页 | 摸头（睡时=被嫌弃）；**它说话时=打断+摸头二合一** |
| tap | 通用 | 确认/选中 |
| 横滑舞台 | 主页 | 切换屋内宠物（瞬移转场） |
| 横滑 | 轮盘类（选豆/短语） | 换选项 |
| 长按 | 列表卡 / 主页舞台 | 上下文菜单（改名/放生…；探险态舞台 = 提前召回） |
| 竖滑 / Digital Crown | 列表 | 滚动 |
| 边缘右滑 | 通用 | 返回（主页为根） |
| 表冠单击 | 任意 | 回表盘（它还在表盘上等你） |

## 9. 动效系统

| 类别 | 规格 |
|---|---|
| 宠物状态机 | 采样器全套平移（呼吸/眨眼/happy/eat/sleep/teleport/annoyed/glitch），30fps |
| 页面转场 | **像素溶解**为主转场（150-250ms）；进入主页=溶解重组；错误/传说=glitch 抖动 |
| 焦点转移 | 宠物瞬移三段（溶解→spinner→重组 810ms）复用为一切"切换"的转场语言 |
| 破壳 | 白闪 1 帧 + 碎片粒子 + 弹性登场 |
| 打字机 | 台词 30-50ms/字，可 tap 跳过 |
| 开箱 | 逐格翻开 + 逐格 Haptic，节奏感优先 |
| 粒子 | 心（happy）、Zzz（睡）、bit 方块（升级/融合）、星尘（放生）——全部 48 网格内像素粒子 |

## 10. Haptic & 声音

| 事件 | Haptic | 音 |
|---|---|---|
| 摸头 | `.rigid` 轻击×1 | 叫声（方波短音，性格参数变音高） |
| 它主动找你 | `.notification` 双击 | 三音上行呼叫 |
| 投喂吸收 | `.click` | 吸收"叮" |
| 开箱逐格 | `.click` 逐格 | 逐格音阶 |
| 破壳/融合成功 | `.success` | 上行琶音 |
| 传说基因 | 重三连 pattern | 全屏 glitch 音 |
| 放生 | 单次轻柔 `.rigid` | 下行两音，克制 |

- 全部音效 = S3 时代的方波基因平移：AudioEngine 合成方波，无采样文件，性格（音高）与基因（glitch 音）参与调制

## 11. AOD 与功耗策略

| 场景 | 策略 |
|---|---|
| 表盘 AOD | 静态休眠帧（呼吸动画都停），像素深底天然省电 |
| 表盘亮屏 | timeline 帧切换（20-30 帧/天预算内） |
| App 前台互动 | 30fps 全动效；离开前台立即降为静态 |
| 后台 | 零活动；健康数据由系统批处理采集 |
| 主动通知 | 一天 ≤2 次（气泡/复杂功能换帧 + Haptic tap），永远可关 |

## 12. 儿童适配与无障碍

- 触控目标 ≥44pt（主按钮 64pt）；单手拇指可达区布置主操作
- 图标先于文字，文字为辅（低龄识字有限）；像素字全部 ≥20pt
