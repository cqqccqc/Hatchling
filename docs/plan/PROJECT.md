## 1. 项目定位

**一句话**：一只住在彩色圆屏挂件里的赛博电子生命——它会瞬移、会 glitch、会记仇、会做梦，用 LLM 当大脑，越养越像"你的"。

- **品类**：AI 电子宠物（Tamagotchi 的骨架 × LLM 的灵魂），**坚决不做效率工具**——失败的 AI 硬件都在做效率，成功的都在做性格
- **核心洞察**：这类产品的玩法只有一把标尺——**"这件事，只有一只记得住事的 AI 宠物做起来才特别吗？"** 记忆 + 性格 + 会说话是独占武器
- **定位（v1.1）**：**个人亲子项目**——先做给自己和儿子玩；泛化目标用户为 **5-10 岁儿童**与想回味童年的年轻人。订阅/商业化暂不考虑，相关章节降级留档
- **留存引擎**：愧疚式回访（它记得你三天没喂它）+ 收集（基因/图鉴）+ 关系（记忆/纪念/心愿）
- **养成原则（v1.1）**：出生即最终态——**天生 = 基因**（外观 + 性格人设，可遗传可繁育）；**后天 = 记忆**（agent memory，越来越懂你）

## 2. 美术方向（已定）

**「抽象电子生命 × 赛博风味」**——明确否决"现实生物感"和"软萌小动物"路线。

- **三种身体原型**（物种即基因）：**数据幽灵**（波浪裙摆·丧萌）/ **悬浮豆荚**（观察窗·尾焰·机灵）/ **晶体核**（菱形旋转·冷酷稀有）
- **规格**：48×48 像素本体 · Endesga-32 色板 · 深底扫描线 + 星尘背景 · 每只宠物本体限 4-8 色（基因控制色板映射）
- **渲染规则**：整数倍放大（48×48 → ×8 = 384px 居中于 466 圆屏）；图层拆分（身体/天线/眼/花纹/配饰）供基因组合
- **赛博语言**：情绪用系统图标（error 弹窗脸 / loading 转圈 / 404 / 低电量蔫）；出现/消失 = 像素溶解；位移 = 瞬移（无腿，省最贵的走路动画）；glitch 频率本身是遗传基因
- **动效资产**（全程序生成）：呼吸 ±1.5px、眨眼、开心蹦跳、进食吸收数据豆（无嘴设计）、休眠待机屏保、瞬移三段（溶解→spinner→重组）（版本升级进度条仪式已随成长系统砍除）
- 待办：正式角色三视图外包画师试稿（itch.io / 米画师，先买 5 张试稿）

## 3. 核心玩法系统（已定）

### 3.0 核心主线（v1.1 定稿，2026-10-19）

```
【开局】星空坠落一颗蛋 → 直接破壳（零等待，仪式感全在坠落）→ PTT 语音取名 → 完全体宠物
【日常】默认主页 = 单宠物互动：对话 / 养成 / 任务
【获得】任务奖励蛋 → 孵化计时 X 分钟（可配置）→ 破壳入屋
【繁育】屋内两只融合 → 新蛋（受冷却闸门约束）→ 孵化 → 入屋
【屋子】列表页 ≤3 只，非激活 = 挂机状态；超出 → 放生（归档）
【循环】基因收集 × 育种筛选（保稀汰庸）× 记忆累积
```

- 语音取名带 ASR 回显确认（防同音字翻车——名字会被 LLM 记一辈子）
- 首蛋直接孵化 = 开机 30 秒内就有一只活的宠物，不让用户等；星空坠落承担全部开局仪式感

### 3.1 养成四件套
| 系统 | 内容 |
|---|---|
| 喂养 | 投喂**数据豆**（知识/玩乐/安眠）三豆风味：不同豆不同动画 + 即时情绪反应，只影响当下不影响长期；**口味偏好 = 基因**（爱吃的转化率高·开心加倍，讨厌的嫌弃脸）；饱食度状态维持（饿了闹、久饿记仇；不做血条式惩罚）；过量 = 变圆卡顿 |
| 作息 | 共栖节律：说晚安→待机屏保；你早睡它才睡；赖床它记仇 |
| 清洁 | 垃圾文件堆积 → **磁盘清理小游戏**；拖久了它动作掉帧（状态 glitch 可视化） |
| 任务·探险（v1.1 统合） | 挂机式：它自己去数据矿洞接委托，**挖矿进度 = 真实计步**（你带它出门，它才挖得动深层矿区）；回家收取 = 每日开箱时刻。奖励分层：数据豆必得 / 稀有部件·朋友的信概率 / **蛋** = 深层矿区·特殊委托限定（周 1-2 颗量级，保育种稀缺性）；宅家保底：浅层只出基础资源 |

### 3.2 天生与后天（v1.1 修订：出生即最终态）
- **无阶段成长**：破壳即完全体——完整对话、全部基因表达。v1.0 的版本升级仪式 / 语言进化 / 进化分支已砍除
- **二分原则**：**天生 = 基因**（外观 + 性格人设，出生定型，只能靠繁育改变）；**后天 = 记忆**（agent memory 持续累积，越来越懂你）
- **性格入基因**：粘人/毒舌/好奇心/勇气 四参数为基因槽的一部分，参与遗传与突变——性格可繁育、可组合（毒舌×粘人=？），育种目标从外观扩展到性格
- **越来越懂你**：对话与互动事件 → 事件溯源（§7）→ 每夜 agent memory 批处理（摘要/情感/纪念日/关系图谱）→ 注入后续对话；懂你的深度 = 记忆密度，是"越养越像你的"的唯一后天载体
- **告别（v1.1 定稿）**：**电子宠物不会死亡**——唯一告别通道是**放生**（主动选择，归档留底，见 §3.4）。疏忽的后果停留在情绪层（饿了闹、记仇），不做生存惩罚；"它永远记得你们的一切"是产品的情感承诺

### 3.3 对话系统
- **输入**：① PTT 按住说话（主入口，松开发送）② 快捷短语轮盘（A 键循环、B 发送，嘈杂环境兜底）③ 手机 App 键盘（BLE）
- **呈现**：像素气泡 + 打字机逐字 + 扫描线；LLM 约束 **≤14 字短句**；等回复时头顶转 loading 圈——延迟体验设计成"它在认真想"
- **规则**：任意键退出；它说话时按 PTT = 打断；回复后 3 秒聆听窗进入连续聊天
- **钩子**：教口头禅（本地词表，隐私可控）；对话结构化返回 `{文本, 动作, 心情变化, 事件}` 直接驱动演出；骂它记仇写进记忆

### 3.4 繁育与稀有基因（详见 rare-gene-lab.html 预览）
- **繁殖 = 数据融合**：屋内任意两只融合产蛋（**单机闭环成立**）；双机 BLE 见面配对为后续增强渠道（亲密度加成等机制保留）；对蛋说话/唱歌可加速孵化
- **基因槽**：物种 / 体色8 / 天线4 / 眼睛3 / 花纹4 / glitch频率3 / 口味偏好 + 性格参数（粘人/毒舌/好奇/勇气）
- **稀有基因三类正交**（外观晒 / 行为活 / 天赋强），首批 12 个：
  - 外观：全息体色、初代机皮肤、脉冲环眼、星尘纹、黑洞核心（豆荚传说）、双生幽灵（幽灵传说）、双子内核（晶体传说）
  - 行为：残影协议、乱数舞步、夜行节律、回声口癖
  - 天赋（克制，+15% 级别）：掘深协议、温暖核心、欧皇协议（突变率×2，传说）
- **机制**：等位基因对（显隐性，稀有多为隐性）；单槽遗传父 42%/母 42%/突变 16%；稀有突变 2.5%/槽、史诗 0.6%、传说 0.08%；**异色个体** 1/96（双亲亲密度 ≥90 时 ×3，把"好好养"和繁殖收益绑死）；10 连保底；配方隐藏基因（如 glitch 高频×2 → 5% 故障体；星际蓝+光环+数据流 → 深空信使）
- **反氪金原则**：基因绝不可直售，只卖便利（融合加速/图鉴扩容）；概率公示
- **孵化仪式**：传说孵化全屏播报「⚠ 检测到未知基因序列」+ 专属破壳动画 + 图鉴 lore（例：黑洞核心——"它吞掉的第一个东西，是自己的出厂设置"）
- **蛋的来源（v1.1）**：首蛋 = 开局星空坠落直接破壳（零等待）；后续蛋 = **任务奖励**（深层矿区·特殊委托限定，周 1-2 颗量级保稀缺），孵化计时 X 分钟（可配置）
- **屋子（v1.1）**：宠物管理列表——列表页即"屋子"，单宠物视图为默认主页；上限 **3 只**，非激活宠物 = 挂机状态
- **放生（v1.1）**：超出 3 只必须放生——用户感受是放生告别仪式，**实现为归档**（基因/血统/图鉴留底，保留"归档宠物回归"伏笔）；它是育种筛选循环的必然出口（保稀汰庸）
- **繁育冷却（v1.1）**：破壳后需相处 N 小时 / 同一对融合 CD N 小时（可配置闸门，防无限刷蛋）

### 3.5 扩展玩法（第一梯队，v1 候选，全零新增硬件）
| 玩法 | 核心 | 依赖 |
|---|---|---|
| **读心猜拳** ⭐ | 它越玩越懂你的出拳习惯，准到吓人；可求它放水 | 事件统计+预测模型；短视频传播神器 |
| **心愿任务** ⭐ | 它主动许愿（看日落/听你唱歌/见见咕噜），**传感器验证现实行为**（光感/录音/BLE） | 状态机+预生成文案 |
| **纪念币** | "永远记住今天"——把某天钉进永久记忆，每年纪念日它会提起 | 记忆系统标记位 |
| **毒舌闹钟** | 性格化叫醒；赖床记仇写进记忆 | RTC 唤醒+TTS |
| **宠物八卦网** | 两只宠物见面互相告状（"咕噜说你上周三天没喂它"） | 双方事件日志+LLM 转述 |
| **数字信鸽** | 给朋友的宠物捎话，**BLE 见面才送达** | BLE 邻近+加密小包 |
| **表情包工厂** | 当前画面+台词直出像素表情包分享 | 屏幕帧+排版，增长杠杆 |

第二梯队（v1.5+）：声音图鉴、梦境交换、家庭多人格、像素工坊 UGC、寄养系统、全服协作事件。

## 4. 交互与硬件映射（已定）

- **形态**：蛋形挂件 Ø46×62mm，约 55-70g，可换硅胶套；磁吸巢穴充电底座（回巢=晚安仪式）
- **按键 3+1**：A 选择（长按快捷环菜单）/ B 确认+打招呼（凸点，长按主菜单）/ C 返回（长按口袋模式息屏静音）/ PTT 侧键按住说话
- **状态复用**：孵化期 A/C 敲蛋壳、PTT 对蛋唱歌；睡时按键不吵醒；工程组合键 A+C 重启、B+PTT+插电配网、三键 10s 出厂
- **传感器**：加速度计（计步/摇晃/敲击）、壳内触摸弹簧（摸头；睡时摸会被嫌弃）、光敏（天黑自动屏保）
- **按键音 = 宠物叫声**（不同键不同音高，复古电子音变成对话）

## 6. 嵌入式 AI 与云端分层（已定）

```
端侧 S3：WakeNet 唤醒词 + MultiNet 离线命令词（~100条）+ 方波音效合成（按键音=宠物叫声）+ 需求循环（永不掉线）
   ↓ PTT 录音（Opus/PCM over Wi-Fi）
云端大脑：流式 ASR（豆包/讯飞，**童声识别率待验证**——5-10 岁用户核心入口）→ LLM（GLM-4-Flash/豆包 lite，≤14字约束+人设+记忆注入+**儿童内容护栏**）→ 流式 TTS（CosyVoice/豆包）
   ↑ 台词批量预生成+缓存（省成本核心手段）；单宠物月成本几毛~几块
二代底座（可选）：RK3566/树莓派网关 = sherpa-onnx 全离线 ASR/TTS + Qwen3-0.6B 本地小脑 + SenseVoice 情绪感知
```

## 7. 软件架构核心：事件溯源（Event Sourcing）

所有玩法共享一个事件系统，新玩法 = 加一类事件，架构零改动：

```
【产生事件】喂食/摸头/对话/见面/步数/录音/任务/闹钟
      ──▶ 事件日志 {ts, type, actors, 情绪标记}（本地环形+云端）
                │ 每夜 LLM 批处理
                ▼
           记忆库（agent memory）：摘要/情感/纪念日/关系图谱
                │ 注入
                ▼
【消费事件】对话上下文 · 做梦 · 日记 · 心愿 · 记仇 · 纪念提醒 · 表情包台词
```

## 8. 商业化原则（留档：当前为个人亲子项目，暂不考虑；日后若推广再启用）

- 硬件溢价 + 免费基础脑 + 高级记忆/对话订阅（定价待定）
- 换壳硅胶套盲盒 = 高毛利周边主引擎；屏内装扮双系统
- 基因不可直售；概率公示；10 连保底
- 不做充值抽蛋；儿童版下沉时另设家长管控

## 9. 待定事项（下次讨论）

1. **首发身体原型**：三选一还是三物种全做（物种即基因）？
2. **童声 ASR 选型验证**：5-10 岁儿童发音的识别率实测（豆包/讯飞等）——语音是核心交互入口，此项开发前优先验证
3. **竞争玩法口味**：读心猜拳它赢了要不要"懂分寸"？
4. **扩展玩法取舍**：整体押后（已裁决），随开发节奏定
5. **节奏参数默认值**：孵化时长 X、繁育冷却 N、任务时长/并发/蛋掉率（机制已定，数值可配置待定）
6. **双机玩法**：父子各一台即成立（装机量=2 够用），优先级上调；正式美术外包对个人项目非必需（程序化生成已够用）
