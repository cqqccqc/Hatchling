## 1. 项目定位

**一句话**：一只住在 Apple Watch 表盘里的赛博电子生命——它会瞬移、会 glitch、会记仇、会做梦，用 LLM 当大脑，越养越像"你的"。

- **品类**：AI 电子宠物（Tamagotchi 的骨架 × LLM 的灵魂），**坚决不做效率工具**——失败的 AI 硬件都在做效率，成功的都在做性格
- **核心洞察**：这类产品的玩法只有一把标尺——**"这件事，只有一只记得住事的 AI 宠物做起来才特别吗？"** 记忆 + 性格 + 会说话是独占武器
- **定位（v1.1）**：**个人亲子项目**——做给自己和儿子（共用同一只手表）玩；泛化目标用户为 **5-10 岁儿童**与想回味童年的年轻人。不考虑商业化
- **留存引擎**：愧疚式回访（它记得你三天没喂它）+ 收集（基因/图鉴）+ 关系（记忆/纪念）
- **养成原则（v1.1）**：出生即最终态——**天生 = 基因**（外观 + 性格人设 + 口味，可遗传可繁育）；**后天 = 记忆**（agent memory，越来越懂你）
- **情感承诺（v1.1）**：**电子宠物不会死亡**——"它永远记得你们的一切"，唯一的告别是主动放生
- **数据现实（v2.3）**：全部数据存手表本地（零云）——卸载 app 即清空；「备份导出」功能列为远期兜底

## 2. 美术方向（已定，平台无关）

**「抽象电子生命 × 赛博风味」**——明确否决"现实生物感"和"软萌小动物"路线。

- **三种身体原型**（物种即基因，**v1 三物种全做**——渲染器已验证、边际成本近零，单物种会让 Gen0 图鉴与融合组合空间塌掉）：**数据幽灵**（波浪裙摆·丧萌）/ **悬浮豆荚**（观察窗·尾焰·机灵）/ **晶体核**（菱形旋转·冷酷稀有）
- **规格**：48×48 像素本体 · Endesga-32 色板 · 深底扫描线 + 星尘背景 · 每只宠物本体限 4-8 色（基因控制色板映射）
- **渲染规则**：整数倍放大（48×48 → ×8 ≈ 384px，适配手表屏居中）；图层拆分（身体/天线/眼/花纹/配饰）供基因组合；渲染逻辑自采样器 JS 直接移植（SwiftUI Canvas / SpriteKit）
- **赛博语言**：情绪用系统图标（error 弹窗脸 / loading 转圈 / 404 / 低电量蔫）；出现/消失 = 像素溶解；位移 = 瞬移（无腿，省走路动画）；glitch 频率本身是遗传基因
- **动效资产**（全程序生成）：呼吸 ±1.5px、眨眼、开心蹦跳、进食吸收数据豆（无嘴设计）、休眠待机屏保、瞬移三段（溶解→spinner→重组）

## 3. 核心玩法系统（已定）

### 3.0 核心主线（v1.1 定稿）

```
【开局】星空坠落一颗蛋 → 直接破壳（零等待，仪式感全在坠落）→ 语音取名 → 完全体宠物
【日常】默认主页 = 单宠物互动：对话 / 喂养 / 任务
【获得】任务奖励蛋 → 孵化计时 X 分钟（可配置）→ 破壳入屋
【繁育】屋内两只融合 → 新蛋（受冷却闸门约束）→ 孵化 → 入屋
【屋子】列表页 ≤3 只，非激活 = 挂机状态；超出 → 放生（归档）
【循环】基因收集 × 育种筛选（保稀汰庸）× 记忆累积
```

- 语音取名带识别回显确认（防同音字翻车——名字会被 LLM 记一辈子）
- 首蛋直接孵化 = 打开 App 30 秒内就有一只活的宠物，不让用户等；星空坠落承担全部开局仪式感

### 3.1 日常三件事（v2.0 手表化）

| 系统 | 内容 |
|---|---|
| 喂养 | 投喂**数据豆**（知识/玩乐/安眠）三豆风味：不同豆不同动画 + 即时情绪反应，只影响当下不影响长期；**口味偏好 = 基因**（爱吃的转化率高·开心加倍，讨厌的嫌弃脸）；饱食度状态维持（饿了闹、久饿记仇；不做血条式惩罚）；过量 = 变圆卡顿 |
| 作息 | 共栖节律 × **HealthKit 真实睡眠数据**：你睡了它先睡，你熬夜它知道（明早没精神 + 记仇）；赖床记仇写进记忆。**每日节律演出（v2.2）**：早晨首次抬腕 = 它冒 `💤✨` 讲一个梦（内容 = 昨夜 agent memory 批处理的产物，"梦是记忆的 UI"）；晚安仪式（说晚安/检测入睡 = 待机屏保）。**毒舌闹钟进 v1**：本地通知零成本，性格化铃声叫你起床（agent memory 的日常应用） |
| 任务·探险（统合） | 挂机式：**每日一次，早上自动出发**去数据矿洞接委托，**挖矿进度 = HealthKit 真实步数**。完成条件：步数达标（默认 4000，**提前收工回家**）或 到达最晚时长（默认 10h，**倒计时兜底**——不出门也必结束，永不卡死）。奖励分档：步数达标 = 标准档（数据豆必得 / 部件概率 / **蛋**机会，深层矿区）；兜底 = 保底档（仅数据豆）。**蛋产出约周 1-2 颗量级，保育种稀缺性**；回家收取 = 每日开箱时刻 |

### 3.2 天生与后天（v1.1 定稿）

- **无阶段成长**：破壳即完全体——完整对话、全部基因表达
- **二分原则**：**天生 = 基因**（外观 + 性格人设，出生定型，只能靠繁育改变）；**后天 = 记忆**（agent memory 持续累积，越来越懂你）
- **性格入基因**：粘人/毒舌/好奇心/勇气 四参数为基因槽的一部分，参与遗传与突变——性格可繁育、可组合（毒舌×粘人=？），育种目标从外观扩展到性格
- **越来越懂你**：对话与互动事件 → 事件溯源（§5）→ 每夜 agent memory 批处理（摘要/情感/纪念日/关系图谱）→ 注入后续对话；懂你的深度 = 记忆密度，是"越养越像你的"的唯一后天载体
- **告别（v1.1 定稿）**：**电子宠物不会死亡**——唯一告别通道是**放生**（主动选择，归档留底，见 §3.4）。疏忽的后果停留在情绪层（饿了闹、记仇），不做生存惩罚

### 3.3 对话系统（v2.0 手表交互版）

- **输入**：① 系统听写（主入口，童声识别待真机实测）② 快捷短语轮盘（横滑气泡，嘈杂环境/懒人兜底）③ iPhone 配套 App 键盘
- **呈现**：像素气泡 + 打字机逐字 + 扫描线；LLM 约束 **≤14 字短句**（对低龄用户天然正确——孩子的表达本来就短）；等回复时头顶转 loading 圈——延迟体验设计成"它在认真想"
- **规则**：点它=打断；回复后短暂聆听窗进入连续聊天
- **触觉**：它叫你时 Haptic tap 手腕一下（手表独占的"拍你肩膀"）
- **钩子**：教口头禅（本地词表）；对话结构化返回 `{文本, 动作, 心情变化, 事件}` 直接驱动演出；骂它记仇写进记忆

### 3.4 繁育与稀有基因（详见 rare-gene-lab.html 预览）

- **繁殖 = 数据融合**：屋内任意两只融合产蛋（**单机闭环成立**）；对蛋说话/唱歌可加速孵化；**双机配对（父子两块表）为后续增强渠道**，优先级随设备到位再议
- **基因槽**：物种 / 体色8 / 天线4 / 眼睛3 / 花纹4 / glitch频率3 / 口味偏好 + 性格参数（粘人/毒舌/好奇/勇气）
- **稀有基因三类正交**（外观晒 / 行为活 / 天赋强），首批 12 个：
  - 外观：全息体色、初代机皮肤、脉冲环眼、星尘纹、黑洞核心（豆荚传说）、双生幽灵（幽灵传说）、双子内核（晶体传说）
  - 行为：残影协议、乱数舞步、夜行节律、回声口癖
  - 天赋（克制，+15% 级别）：掘深协议、温暖核心、欧皇协议（突变率×2，传说）
- **机制**：等位基因对（显隐性，稀有多为隐性）；单槽遗传父 42%/母 42%/突变 16%；稀有突变 2.5%/槽、史诗 0.6%、传说 0.08%；**异色个体** 1/96（双亲亲密度 ≥90 时 ×3，把"好好养"和繁殖收益绑死）；10 连保底；配方隐藏基因（如 glitch 高频×2 → 5% 故障体；星际蓝+光环+数据流 → 深空信使）
- **遗传模型 v2.1（CryptoKitties 式三层基因槽）**：每个外观性状槽位存三层——**表达层**（现在长什么样）/ **携带层**（隐性）/ **祖源层**（更深的隐性）。融合时三层各自独立 50/50 取自父母，后代重新洗牌排序，祖源层稀有/史诗基因有小概率上浮表达。效果：稀有表现的隔代浮现由机制保证（**传说例外：纯低概率突变，不可遗传、不参与上浮、无保底**）；图鉴公开携带层（育种可视化，大孩子研究配方），孩子无感、只管惊喜
- **代数 Gen（v2.1）**：开局星空坠落蛋与任务野生蛋 = **Gen0（星生代）**；后代 Gen = max(父, 母) + 1。Gen 只做记录与荣誉（血统谱的树根永远是星生代），不设价值惩罚——个人项目不搞稀缺经济学
- **繁育疲劳（v2.1，冷却递增）**：每只宠物每参与一次融合，自身冷却翻倍：4h → 8h → 16h → 封顶 48h（可配置）。鼓励轮换育种队伍，新孵的宠物永远有价值；与"繁育冷却"闸门合并，取代固定 CD
- **血统谱（v2.1）**：每只宠物记录父母 / 代数 / 融合次数；图鉴新增「血统谱」树状追溯页（iPhone 大屏展示，手表只显 Gen 徽标）；**放生归档不删谱系**——血脉永续，每只宠物身上带着整棵树的故事
- **孵化仪式**：传说孵化全屏播报「⚠ 检测到未知基因序列」+ 专属破壳动画 + 图鉴 lore（例：黑洞核心——"它吞掉的第一个东西，是自己的出厂设置"）
- **蛋的来源**：首蛋 = 开局星空坠落直接破壳（零等待）；后续蛋 = **任务奖励**（深层矿区·特殊委托限定，周 1-2 颗量级保稀缺），孵化计时默认 **30 分钟**（可配置）
- **屋子**：宠物管理列表——列表页即"屋子"，单宠物视图为默认主页；上限 **3 只**；**3 只全部并行挂机**（各自探险/生活/吃进度，切换宠物只换交互对象，另两只不是摆件）（v2.2）
- **放生（v2.2 儿童化叙事）**：屋子满员时，由**宠物先表达远行愿望**（`🌍✈️` "我想去看看世界"）——孩子的动作是**送它远行**而不是抛弃它；仪式=放生告别，**实现为归档**（基因/血统/图鉴留底，保留"归档宠物回归"伏笔）；它仍是育种筛选循环的出口（保稀汰庸），但心理体验从"选择舍弃"变成"目送愿望"
- **繁育冷却**：破壳后需相处 **24 小时**方可参与融合（可配置闸门，"住上一天才能当父母"）；参与后的 CD 走「繁育疲劳」递增（4h→8h→16h→封顶 48h，可配置）

### 3.6 宠物社交（v2.1 新增）

**原则：宠物去社交，不是用户去社交。** 没有好友列表、没有聊天、没有动态流——一切社交行为被叙事为"宠物自己的生活"，用户只做三个动作：**点头同意 / 送出门 / 迎接回家**。社交系统与繁育一体两面（社交的终点常常是融合）。

| 层 | 玩法 | CryptoKitties 对应 | 优先级 |
|---|---|---|---|
| **双星同孵** | 两台设备各出一只 → 融合仪式在两块表上同步演出 → **双方各得一颗同源蛋（双胞胎）**：基因相同，体色/性格/异色各自独立 roll——两台设备各养一只"同源"宠物，长大后性格互补 | 两猫配种、双方共有后代 | **P0**（两块表即启用） |
| **做客（寄宿）** | 宠物打包成数据包去朋友的表住 1-3 天：住**客房**（不占 3 只上限）；期间两只宠物自主互动——一起下矿（步数共享加成）、交换八卦；回家带回**旅行记忆**（agent memory 新条目：它会讲朋友家的事）+ 伴手礼（稀有部件/数据豆） | sire 借配的社交化变体 | **P1** |
| **相亲（挂牌）** | 把自家宠物挂牌"可配种" → 对方设备选中 → 双方各得一颗蛋（免费交换，去金钱化） | sire auction 去货币化 | P2（远期） |

- **客房**：屋子的第 4 个卡位，仅住访客——卡片带「客」角标 + 回家倒计时，到期自动回归主人设备。**3 只上限是家人，客房是流动的**，放生的育种压力不被社交污染
- **社交的情感杠杆**：做客归来的宠物会主动提起朋友家的事（"那个紫色的家伙睡觉会发光！"）；对方的宠物也会在你家留下故事——agent memory 让社交沉淀为两只宠物各自的记忆，而不是聊天记录
- **血统互通**：跨设备融合的后代让血统谱长出"别人家的星生代"分支，图鉴收集从单机扩展到家庭圈
- **隐私边界**：宠物数据包只含基因/状态/记忆摘要，不含主人个人信息；一切传输需主人主动发起或点头
- **技术载体（v2.3 调整）**：CloudKit 通道已随零云化移除；双机传输改走 WatchConnectivity（需配套 iPhone 中转）或面对面方案——**社交层整体暂缓**，待传输方案重议后按 P0→P2 顺序恢复

## 4. 平台方案：Apple Watch（v2.0）

### 4.1 双前端架构

iPhone App 和 Watch App 是**同一只宠物的两个前端**，共享同一份数据（Xcode 单工程双 target）：

```
┌─ iPhone App（育种工作室 · 大屏）──────────────┐
│  图鉴 · 血统谱系 · 融合实验室 · 记忆相册        │
│  （"它记得的 137 件事"在手机上看才爽）          │
└───────────────┬──────────────────────────┘
                │
   ① SwiftData 本地存储（App Group 容器共享）← 主通道
      宠物状态/基因/事件日志/记忆库，同一份数据（v2.3 零云化）
   ② WatchConnectivity（设备直连）← 即时信号（🚧 暂缓：随社交传输层重议）
                │
┌───────────────┴──────────────────────────┐
│ Watch App（贴身日常 · 手腕）                │
│  主页单宠互动 · 喂豆 · 听写对话 · 屋子列表    │
│  表盘复杂功能（常驻低频动画）                │
│  HealthKit 步/心/睡 → 事件日志              │
└──────────────────────────────────────────┘
```

**分工**：手表是宠物**住**的地方（全天陪伴 + 轻互动），iPhone 是**育种工作室**（重操作放这）。
**v1 范围（v2.2 定稿，v2.3 零云化）**：**纯手表单打**——只做 watchOS target；数据层（HatchlingKit）从第一天按跨端设计，iPhone 端二期只加 UI 不动核心。**数据 100% 本地**：无 CloudKit/iCloud；卸载 app 即数据丢失——「备份导出」（存档 JSON）列为远期功能

### 4.2 全天式展示：表盘常驻

- 宠物住在**表盘复杂功能（Complication）**里——抬腕看时间 = 顺便看它一眼，数字版的"戴在手腕上的挂件"
- 点开进 App = 互动模式（喂豆 / 对话 / 屋子 / 融合）
- **WidgetKit timeline 预生成低频帧**：表盘上的它每隔几分钟换一帧（换个位置、翻个身、偶尔 glitch）——平台刷新预算限制恰好成全"白天低存在感"设计原则
- Always-On Display 下显示静态帧（休眠姿态）

### 4.3 HealthKit 玩法化（手表独占武器）

| 数据 | 玩法映射 |
|---|---|
| 步数 | 矿洞任务进度（原加速度计方案的健康数据升级版，精度更强） |
| **心率** | **它知道你心跳**：跑步时它喊加油；心率异常飙高，晚上它会问你怎么了 |
| **睡眠分期** | 共栖节律真实化：熬夜它知道、赖床记仇有真实依据 |
| Haptic | 摸头轻震一下（"电子宠物有触感"）；它主动找你 = tap 手腕 |

### 4.4 交互映射（硬件 → 手表）

| 原硬件方案 | 手表方案 |
|---|---|
| PTT 按住说话 | 系统听写 / 语音识别（设备端优先，童声识别率待实测） |
| 3 个物理键 + 触摸弹簧 | 触摸：点它=摸头 · 横滑=轮盘/切换 · 长按=菜单 |
| 按键音 = 宠物叫声 | 保留音频 + 加 Haptic 触觉 |
| 加速度计计步 | HealthKit 步数 |
| 光敏作息 | 真实睡眠分期 + 系统时间 |

### 4.5 技术选型

| 项 | 选型 |
|---|---|
| App 框架 | SwiftUI（watchOS target + iOS target 同工程）；设计语言跟手 watchOS 26 |
| 最低版本 | **watchOS 11**（v2.2 复核：26 的独占特性零依赖；11 覆盖表盘 WidgetKit + 睡眠分期 + SwiftData + 听写 API，且 SwiftData/WidgetKit 相比 10.0 更成熟稳定；设备兼容 Series 6 及以上，将来给孩子的二手表注意选 S6+；实机 26 不受影响） |
| 表盘常驻 | WidgetKit Complications（accessoryCircular / Corner 等）+ timeline 预生成帧 |
| 数据同步 | **SwiftData 纯本地**（App Group 容器；无 CloudKit——不申请开发者账号）；WatchConnectivity 即时信号 🚧 暂缓 |
| 像素渲染 | SwiftUI Canvas / SpriteKit；48×48 网格整数倍放大（采样器 JS 逻辑移植） |
| 语音输入 | 系统听写 / SFSpeechRecognizer（设备端）；童声识别真机实测后再定云端兜底 |
| LLM 链路 | **Watch 直连云端**：ASR → LLM（≤14字 + 人设 + 记忆注入 + **儿童内容护栏**）→ 流式 TTS；对话突发短，结束即回挂机 |
| 记忆批处理 | iPhone BGProcessingTask 夜间跑（或云端函数），产物经 CloudKit 同步到表 |
| 健康数据 | HealthKit：HKStatisticsQuery（步数）/ 心率（即时+静息）/ 睡眠分期 |

### 4.6 单一主人设定（v2.2 定稿）

- **不分用户**：这台表 = 一个主人。宠物眼里没有爸爸/儿子之分，谁喂都认——**就当一个人玩**
- 父子区分方向已否决；agent memory 的关系图谱保留技术扩展能力（未来若需要再说），v1-v2 不做

## 5. 软件架构核心：事件溯源 + agent memory

所有玩法共享一个事件系统，新玩法 = 加一类事件，架构零改动：

```
【产生事件】喂食/摸头/对话/步数/心率/睡眠/任务/融合
      ──▶ 事件日志 {ts, type, actors, 情绪标记}（设备本地 + CloudKit）
                │ 每夜批处理（iPhone 后台 / 云端）
                ▼
           记忆库（agent memory）：摘要/情感/纪念日/关系图谱
                │ 注入
                ▼
【消费事件】对话上下文 · 做梦 · 日记 · 心愿 · 记仇 · 纪念提醒
```
